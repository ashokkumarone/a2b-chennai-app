# A2B (Adyar Ananda Bhavan) - Chennai Flagship Mobile App

A production-grade, high-fidelity consumer web application prototype for **A2B (Adyar Ananda Bhavan)** based in **Chennai, Tamil Nadu**.

---

## 🌟 What's New in this Professional Edition

1. **Ultra-Clean Consumer UX (Clutter-Free)**
   - All demo simulation tools, strategy banners, and admin text have been removed from the user interface.
   - Built with an authentic Apple iOS / Android luxury mobile shell with live status bar, subtle shadows, glassmorphism headers, and smooth micro-interactions.

2. **Chennai Base Location & Branch Switcher**
   - Default Location: **Adyar, Chennai** (Gandhi Nagar).
   - Easily switch between famous Chennai A2B branches:
     - **A2B Adyar Flagship (L.B. Road)** — 1.4 km (18 mins delivery)
     - **A2B T. Nagar (Venkatanarayana Road)** — 4.2 km (30 mins delivery)
     - **A2B Mylapore (R.K. Mutt Road)** — 2.8 km (22 mins delivery)
     - **A2B Velachery (100 Feet Bypass Road)** — 3.6 km (25 mins delivery)
     - **A2B OMR (Thoraipakkam IT Corridor)** — 6.1 km (35 mins delivery)

3. **Authentic A2B Menu & Exact In-Store Prices**
   - **Tiffin:** Special Ghee Roast (₹85), Ghee Sambar Mini Idli 14 pcs (₹75), Pongal Vada Combo (₹95), Medu Vada (₹25), Podi Ghee Dosa (₹95), Poori Masala (₹80).
   - **Sweets:** Signature Ghee Mysore Pak (₹185), Pure Kaju Katli (₹260), Motichoor Laddu (₹155), Tirunelveli Wheat Halwa (₹165).
   - **Savouries / Karam:** Madras Special Mixture (₹75), Ribbon Pakoda (₹70), Traditional Kai Murukku (₹80).
   - **Meals:** A2B Grand South Indian Meals Thali (₹175), Curd Rice (₹70).
   - **Chaat:** Special Pani Puri 8 pcs (₹60).
   - **Beverages:** Kumbakonam Degree Filter Coffee (₹35).

4. **Dynamic Distance-Based Delivery Rider Fee Engine**
   - Automatically calculates the fair delivery partner fee based on actual distance (km) from the selected Chennai branch:
     - **Up to 2.0 km:** Base fare = **₹25.00**
     - **2.0 km to 6.0 km:** Base ₹25 + ₹7.00/km
     - **Beyond 6.0 km:** Base ₹25 + (4 × ₹7) + ₹10.00/km
   - **100% of this fee goes directly to the delivery person** with zero platform commission deductions.
   - Interactive distance slider in the cart allows testing different Chennai delivery distances (0.5 km to 12 km).
   - Optional Rider Tip selection (₹10, ₹20, ₹30).
   - Store Pickup (Takeaway) toggle with ₹0 fee.

5. **Dedicated Profile / Account Screen**
   - **Customer Profile:** S. Ramanathan (+91 98427 12345, Gold Member).
   - **A2B Pay Wallet:** Live balance (₹450.00) with 1-click ₹200 top-up.
   - **Loyalty Rewards:** 280 Points (worth ₹140) with redemption button.
   - **Saved Addresses:** Switch between Home (Adyar), Work (OMR IT Park), and Parents (Mylapore).
   - **Past Order History:** 1-Click reorder feature.
   - **Dietary Preferences:** Strict Jain dietary toggle, Tamil/English language indicator, customer care hotline.

6. **Order Placement & Live Tracking Screen**
   - Animated delivery timeline and simulated route map from A2B kitchen to the customer's home in Chennai.
   - Assigned delivery partner details: *Karthik Raja (4.9 ⭐, 1,420 deliveries)* with instant call button.
